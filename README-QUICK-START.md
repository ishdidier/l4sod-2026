# Car Management API - quick start

1. Install Node.js and MySQL (or use XAMPP MySQL).
2. In phpMyAdmin or MySQL Workbench, run all SQL from `database.sql`.
3. Copy `.env.example` to a new file named `.env`, then set your MySQL username/password.
4. In this folder terminal run: `npm install`
5. Start: `npm run dev` (or `npm start`)
6. Test in Postman / Thunder Client at `http://localhost:3000`.

Important: never push `.env` or `node_modules` to GitHub.
